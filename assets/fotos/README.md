# Fotos oficiais

Coloque aqui as imagens reais da dupla e substitua cada placeholder da galeria em `index.html` por:

```html
<img src="assets/fotos/nome-da-foto.jpg" alt="Descricao objetiva da foto">
```

Use imagens otimizadas para web, de preferencia em JPG ou WebP, com largura entre 1200px e 1800px.
